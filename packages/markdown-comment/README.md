# Markdown Comment

`markdown-comment` is the Markdown-commenting capability in AI Workbench. It will provide a shared comment model and public CLI, with VS Code, Skills, and future IDE or local-web views as adapters.

The package is currently a migration landing zone. Its present Rslib files are starter code, not the intended architecture. Before changing this package, read the [repository guide](../../AGENTS.md) and [architecture](../../docs/architecture/markdown-comment.md).
